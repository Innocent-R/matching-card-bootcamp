Project: Matching Card Game

The matching card game is played by one person at a time and helps to improve the memory by remembering the position of the first card. The game ends when all cards are flipped and all got their matches.

How It's Made: Tech used: HTML, CSS, and JavaScript

Lessons Learned: I learned how to use the Math.random() method which helped to shuffle the cards
